# Contributing / 贡献说明

Keep changes within Arc and required shared capabilities. Include the source commit, reproduction, and actual checks. Run the smallest relevant unit test after module changes, then formatting, lint, build, client typecheck, dedicated PostgreSQL integration, both browser projects, and license checks before handoff. Never point tests at production. Report unavailable external gates honestly.

Chain access stays read-only. Unknown is not zero. Preserve raw evidence, immutable reports, exact amounts, permissions, pagination, and attribution. Fixtures belong only under tests. Use permissively licensed code. Do not force-push shared history or publish secrets and private bundles.

修改限于 Arc 及必要共享能力，注明源码、复现和真实检查结果。模块修改后执行相关最小测试，交付前执行格式、lint、构建、客户端类型检查、专用 PostgreSQL 集成、桌面/手机浏览器和许可证检查。不要连接生产数据库做测试，不可执行门禁如实记录。

链始终只读，未知不能归零。保留原始证据、固定报告、精确金额、权限、分页和来源。fixture 只用于测试，代码使用兼容许可证。不要强推共享历史或发布凭据、私有原件。
